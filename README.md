# Склад в ПВЗ — калькулятор дохода и проверка стеллажа

Посадочная страница для владельцев пунктов выдачи: считает доход от программы
хранения товаров продавцов и проверяет, выдержит ли стеллаж 120 кг.

Открыть: **https://seminyuri.github.io/sklad-v-pvz/**

Физика полки в `calc.js` — перенос из движка расчёта (`calc/stellazh.py`) один в
один, по ГОСТ Р 55525-2017: прочность, прогиб L/200 и местная устойчивость
сжатой полки по формуле Винтера. В файле лежит самопроверка на пяти контрольных
точках: расхождение с движком печатается в консоль.

Перед запуском заменить `TG_USER` в `index.html` на аккаунт приёма заявок.

## Шрифты

Лежат рядом со страницей, а не берутся с Google Fonts: у Google знак рубля
U+20BD входит в набор latin-ext, и на странице про деньги он тянет этот набор
для каждого начертания — 104 КБ из 234 ради одного символа.

Нарезаны под страницу: 52 КБ вместо 234. Пересобираются скриптом
`tools/fonts/subset.py` в рабочем репозитории, покрытие символов стережёт
`tools/fonts/check.py`. Лицензия шрифтов — `fonts/OFL.txt`.
